# 101-kali-marceau-

## 📘 Kali Linux 101 — Cours pour débutants

Formation en français de **10 chapitres** sur Linux, le terminal, les réseaux, Python et les bases de la cybersécurité défensive.

- 🖥️ **[Interface web (fond noir, texte blanc)](index.html)**
- 📖 **[Cours complet en Markdown](COURS_KALI_101.md)**

**Branche de développement :** `develop`.

Les exercices avec Nmap se limitent à `127.0.0.1` (boucle locale). Tous les tests doivent être réalisés dans un environnement personnel ou explicitement autorisé.

> Pour voir la page, ouvrir `index.html` dans un navigateur après avoir récupéré le dépôt. Le fichier est présent dans GitHub; GitHub Pages doit être configuré séparément pour avoir un site public.
