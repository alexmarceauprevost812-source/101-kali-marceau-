Chapitre 01 / 10

Découvrir Kali Linux

Kali Linux est une distribution Linux conçue pour l'apprentissage de la sécurité et les audits autorisés. La première compétence est de comprendre ce que le terminal affiche.

Terminal • Identification
whoami
pwd
cat /etc/os-release
uname -r
date

whoami affiche ton utilisateur, pwd ton dossier, uname -r le noyau et date l'heure.

✎ Exercice Trouve le nom de ta distribution, ton utilisateur et ton dossier personnel.

Chapitre 03 / 10

Permissions, processus et stockage

Les permissions r, w, x signifient lire, écrire et exécuter. Observe celles d'un fichier qui t'appartient.

Terminal • Observation
ls -l ~/kali101/chapitre2/note.txt
stat ~/kali101/chapitre2/note.txt
ps -u "$USER"
df -h
free -h
✎ Exercice Repère le propriétaire de note.txt et sa taille. Ne touche pas aux permissions des fichiers système.
Chapitre 04 / 10

Mettre Kali à jour

Comprends les changements avant de lancer une mise à niveau. Sauvegarde les données importantes.

Terminal • Vérification
sudo apt update
apt list --upgradable

Pour appliquer les mises à niveau après avoir lu les modifications proposées :

Terminal • Mise à niveau
sudo apt full-upgrade
✎ Exercice Explique la différence entre récupérer la liste des paquets et installer leurs nouvelles versions.
Chapitre 05 / 10

Les bases du réseau

Une adresse IP identifie un appareil sur un réseau, un port identifie un service, et DNS traduit les noms de domaine. 127.0.0.1 est l'adresse de boucle locale de ton ordinateur.

Terminal • Boucle locale
ping -c 3 127.0.0.1
✎ Exercice Avec tes mots, quelle est la différence entre une adresse IP et un port ?

Chapitre 07 / 10

Premier exercice Nmap en local

Démarre un petit serveur sur ton PC. Dans un premier terminal :

Terminal 1 • Serveur de laboratoire
mkdir -p ~/kali101/site
printf '<h1>Laboratoire Kali 101</h1>\n' > ~/kali101/site/index.html
cd ~/kali101/site
python3 -m http.server 8000 --bind 127.0.0.1

Puis, dans un deuxième terminal :

Terminal 2 • Vérification locale
curl -I http://127.0.0.1:8000
nmap -p 8000 127.0.0.1

Si Nmap n'est pas installé : sudo apt update puis sudo apt install nmap. Un port open signifie qu'un service répond; cela ne prouve pas l'existence d'une faille.

✎ Exercice Arrête le serveur avec Ctrl+C, puis compare le résultat de Nmap sur 127.0.0.1.
Chapitre 08 / 10

Python : vérifier un fichier

Écris ce programme dans ~/kali101/sha256.py. Il calcule une empreinte SHA-256 de ton fichier de cours.

Python 3 • sha256.py
from pathlib import Path
import hashlib

fichier = Path.home() / "kali101" / "chapitre2" / "note.txt"
if fichier.is_file():
    print(hashlib.sha256(fichier.read_bytes()).hexdigest())
else:
    print("Fichier introuvable :", fichier)
Terminal • Exécution
python3 ~/kali101/sha256.py
✎ Exercice Modifie note.txt, recalcule l'empreinte et compare les résultats.
Chapitre 09 / 10

Journaux et sécurité défensive

Les journaux permettent de mieux comprendre les événements d'un système.

Terminal • État du système
journalctl -b -n 20 --no-pager
systemctl --failed

Protège tes comptes avec des mots de passe uniques, l'authentification multifactorielle, les mises à jour et des sauvegardes. Évite de publier tes journaux complets, qui peuvent contenir des données privées.

✎ Exercice Choisis une ligne d'un journal et explique son sens sans divulguer de données personnelles.
